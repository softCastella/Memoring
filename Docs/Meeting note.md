# Meeting note — Memoring 1차 구현

- 날짜: 2026-09-17
- 참석: 운영자, 모바일 앱 개발
- 목적: 감성 체크리스트 앱 1차 범위 구현 결과를 정리하고, 다음 작업을 남긴다.

## 결정

- 기존 저장소에는 README만 있었으므로 Android 우선 Flutter/Dart 프로젝트로 시작했다.
- 앱 표시 이름은 아직 확정되지 않았다. `lib/config/app_config.dart`의 `AppConfig.appName`만 바꾸면 된다. 네이티브 런처 이름은 AndroidManifest / Info.plist에도 맞춰야 한다.
- 최초 실행 기본 디자인은 사진 없는 로즈 테마(웜 아이보리 배경, 브라운 글자, 더스티 로즈 포인트)다. 사진 배경과 반투명 카드는 사용자가 선택했을 때만 적용한다.
- 1차에서는 외부 서버·유료 호스팅·실제 결제를 만들지 않는다.
- 사용자 개인 할 일·감정 메모를 운영자가 보는 기능은 만들지 않는다.

## 이번에 구현한 것

### 앱 (오늘 / 기록 / 꾸미기 / 설정)

- 오늘: 날짜 선택, 월~일 주간 줄, 전체·할 일·업무·공부·루틴 분류
- 항목 추가·수정·삭제·완료/완료 취소. 제목, 날짜, 분류 저장
- 선택한 날짜의 완료 수 / 전체 수, 빈 화면 안내, `+ 할 일 추가`
- 루틴은 매일 반복되고, 완료는 날짜별로 따로 저장된다. 어제 기록이 오늘에 덮이지 않는다.
- 기록: 지침·차분·평온·설렘·기쁨, 짧은 메모, 저장, 지난 날짜 조회
- 꾸미기: 로즈 / 세이지 / 오트 / 나이트. 갤러리 이미지 위치·확대·흐림·카드 투명도, 적용 전 미리보기, 배경 제거, 기본 디자인 복원
- 선택한 이미지는 앱 문서 폴더에 복사해 임시 경로에 의존하지 않는다.
- 할 일, 루틴 완료, 감정, 꾸미기 설정을 기기 로컬 JSON에 저장. 네트워크 없이 1차 기능 사용 가능. 첫 실행 실제 데이터는 비어 있음.

### 운영자 배경 관리 (로컬 웹)

- 실행: `flutter run -d chrome -t lib/admin_main.dart`
- 배경팩 생성·수정, 이미지 등록·순서 변경·삭제
- 팩 이름, 소개, 카테고리, 무료/유료, 비공개/공개
- 유료는 금액 숫자가 아니라 스토어 상품 ID를 적는다. 관리자 화면의 숫자만으로 결제 금액이 바뀌지 않는다.
- 관리자 비밀번호는 앱 소스에 넣지 않는다. 개발 모드에서 브라우저/기기에만 저장하거나 `--dart-define=ADMIN_PASSWORD=`로 전달한다.
- 지금은 이 관리자 화면에만 저장된다. 앱 스토어·서버와는 아직 연결되지 않았다.

## 실행 방법

앱:

```bash
flutter run
```

이 환경에는 Android cmdline-tools가 없어 에뮬레이터/실기기 실행은 확인하지 못했다.

관리자 화면:

```bash
flutter run -d chrome -t lib/admin_main.dart
```

## 검증 결과

- `flutter analyze`: 이슈 없음.
- 단위 테스트: 항목 CRUD, 날짜 분리, 루틴 날짜별 완료, 재실행 후 유지, 테마 복원, 배경 파일 복사, 배경팩 로컬 저장은 통과했다.
- 위젯 테스트 2건은 아직 실패한다.
  - 오늘 화면에서 항목 추가 후 완료 수 텍스트가 바로 갱신되지 않음 (`MaterialApp`이 컨트롤러 변경마다 다시 그려지는 문제로 보임).
  - 작은 화면에서 꾸미기 테마 칩(`로즈`) 스크롤 검증 실패.
- 갤러리 선택, 실제 키보드, 실기기 레이아웃은 에뮬레이터가 없어 실행 검증하지 못했다.

## 아직 구현하지 않은 것

- 실제 Android 홈 화면 위젯 (앱 안 미리보기와 다름)
- 앱 안 배경 스토어, 내 배경, 다운로드, 결제, 구매 복원
- 외부 서버, 운영용 관리자 웹 배포, 운영 인증
- 구독

## 후속 작업

1. 위젯 테스트 2건 수정. `MaterialApp`을 항목 변경마다 다시 만들지 않도록 `lib/app.dart` 구조를 나눈다.
2. Android cmdline-tools / 에뮬레이터 또는 실기기를 준비한 뒤 앱 실행 검증. 특히 갤러리 배경, 키보드, 작은 화면.
3. 홈 화면 위젯
   - 소형: 오늘 완료 수·진행률
   - 중형: 오늘 할 일 일부와 체크
   - 앱과 완료 상태 동기화. 저장 파일 `data/widget_snapshot.json`을 쓸 수 있다.
   - Android Glance 또는 home_widget + 네이티브 작업이 필요하다. 앱 안 미리보기만으로 완료로 보지 않는다.
4. 배경 스토어 (앱)
   - 팩 목록·카테고리·미리보기, 무료/유료, 내 배경, 다운로드·적용
   - 구매 권한은 서버 검증. 클라이언트 구매 여부만으로 유료 콘텐츠를 열지 않는다.
5. 관리자 웹 운영 연결
   - 실제 인증, 이미지 스토리지, 공개 팩을 앱이 서버에서 받도록 연결
   - 앱 재배포 없이 배경 추가가 목표
6. Play Console 상품 ID와 관리자의 `storeProductId` 연동. 관리자 화면에서 금액만 바꿔 결제가 바뀌게 만들지 않는다.

## 다음 단계에 필요한 외부 설정

- Android SDK cmdline-tools, 에뮬레이터 또는 실제 기기
- 홈 위젯용 Android 네이티브/Glance 작업
- 배경 파일 호스팅과 구매 검증 서버
- Play 인앱 상품, 스토어 결제 계정 (없으면 실제 결제로 보고하지 말 것)
- 관리자 웹 운영 배포 시 인증 제공자 (비밀번호를 앱 코드에 넣지 말 것)
